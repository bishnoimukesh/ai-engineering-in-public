# Daily Content Format

Every day's `README.md` uses this structure:

```
Day [N]: [Topic]
Roadmap Section / Difficulty / Learning Objective

1. Understand the Topic
2. LinkedIn Post
3. X (Twitter) Post
4. Image Generation Prompt
5. Key Takeaways
6. Practical Implementation
7. Interview Preparation
8. Learning Resources
```

## LinkedIn post rules

- Open with a strong hook. Write in plain, conversational language and include a practical example.
- Add code when it helps, explain why the topic matters, and list key takeaways.
- End with a question for readers.
- Add 5 to 8 hashtags.

## X (Twitter) post rules

- A single post of **280 characters or fewer**, counted before publishing and noted in the README.
- It carries the same core idea as the LinkedIn post: one sharp hook plus the key insight, without repeating the whole post.
- No links in the post itself, since each link uses 23 of the 280 characters. Put the GitHub link in a reply instead.
- Include "Day N" so the series stays recognizable.
- Use 1 to 3 hashtags at most, and few or no emojis.
