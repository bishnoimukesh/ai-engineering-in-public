# Image Style Guide

Every daily infographic follows these rules, so the series looks consistent.

## Rules

1. **No roadmap references in images.** Don't put any roadmap name, roadmap.sh URL, or "Roadmap" label in the image. This covers the header, the footer and the body.
2. **Canvas:** 1080 × 1350 px (4:5 portrait).
3. **Header:** a "DAY NN" peach pill, with the small gray caps label "AI ENGINEERING SERIES" next to it. Then a large bold title and a one-line subtitle.
4. **Footer:** a thin divider line, then left-aligned text "Learning AI Engineering in public" with "AI Engineering" in deep orange. Nothing else goes in the footer.
5. **Content:** the image explains the concept visually with diagrams, flows, comparisons and icons. Use short labels only, no paragraphs.
6. **No** photos, people, brand logos, 3D effects or clutter. All text must be spelled exactly as written.
7. **No big gap above the footer.** The content fills the canvas evenly, with about 40px between the last content block and the footer divider. In the HTML source, the footer sits in the normal page flow (not absolutely positioned) and the main diagram section stretches to fill the extra height.

## Palette

| Use | Color |
|---|---|
| Background | `#F8F5F1` soft cream, faint dot grid (`#ECE5DC`) |
| Card | `#F8F4F0`, border `#E3DCD3`, radius 16–20px |
| Highlighted card | `#FCF4EB`, 2px border `#EA8417`, soft orange glow |
| Primary accent (borders, arrows) | `#EA8417` |
| Icons | `#E5780A` |
| Accent bars | `#EF932E` |
| Deep accent (highlighted labels and titles) | `#C84D00` |
| Pill | `#FCCC9D` background, `#871B00` text |
| Tags | `#FBE5CD` background, `#871B00` text |
| Muted accent (secondary or "other side" items) | `#A3998B`, card `#F5F1EC` |
| Soft orange card | `#FDEFE1`, border `#F7BA7B` |
| Text | `#141414` main, `#7C7978` secondary, `#6E6C6C` captions |

## Typography

Inter (or a similar geometric sans-serif). The title is 72–76px ExtraBold. Labels are 15–17px caps with wide letter spacing. Body labels are 19–24px.
